# 报告样例 · 键盘延迟探针（kbdprobe）

> **本页数据是 `--selftest` 的合成数据，不是真实采样**——用于展示报告结构与判读口径。
> 合成剧本：4 键正常打字 → 3 键突发 → 一次 700ms 故意长按（带 3 个自动重复）→ 一次 450ms 粘滞样按键（无自动重复）→ 900ms 人为停顿 → 收尾；处理延迟在收尾键上注入了一个 250ms 尖峰。
> 真实采样的报告与此同构；字段含义与判读步骤见 [README.md](README.md) §三。

**这份样例怎么读**（对照 README §三判读步骤）：

- 结论行两个「有」→ 合成剧本故意埋的证据：迟滞（注入的 250ms 尖峰）+ 粘滞（450ms 无 repeat 伴随）。
- 700ms 长按**没有**被算成粘滞：因为它带 3 个自动重复（repeat 流正常），这就是「异常按住」与「故意长按」的区分方式。
- 卡顿点 3 个中，400/450/950ms 是剧本里埋的间隔；**down→repeat 的 550ms（系统重复延迟）被正确剔除**，200ms 整（边界值）不计。
- 真实使用时：`主机` 行是真实系统信息，`系统快照` 是真实 PDH/powercfg 读数；样例里是占位。
