# WinCtlPanel —— 桌面浮窗控制面板

Windows 未激活时「设置 → 个性化」整类被锁。这个工具把常用个性化功能从底层做回来
（DDC/CI + 注册表 + SystemParametersInfo），不经过设置面板。

> **声明：本工具不碰激活本身。** 不做任何破解、KMS、激活工具，不改变 Windows 授权状态。
> 它只是绕过被锁的设置 UI，直接调用系统本来就存在的底层接口。请用于自己的机器。

## 文件

| 文件 | 说明 |
|---|---|
| `WinCtlPanel.ps1` | 主程序（PowerShell 5.1 + WinForms，零依赖，Windows 自带） |
| `启动.cmd` | 双击启动（隐藏控制台窗口，会有约 0.5 秒控制台闪烁，属正常） |
| `README.md` | 本文件 |
| `测试记录.md` | 每项功能的实测结果 |

## 功能一览

| 功能 | 实现方式 | 生效速度 | 说明 |
|---|---|---|---|
| 屏幕亮度 | DDC/CI（dxva2.dll） | 立即 | 外接显示器专用，多屏每个屏一个滑块，200ms 防抖 |
| 深色 / 浅色 | 注册表 `Themes\Personalize` + WM_SETTINGCHANGE 广播 | 立即 | 应用/开始菜单/资源管理器即时变色 |
| 强调色 | 注册表 `AccentColor` / `ColorPrevalence`（ABGR 顺序） | 立即 | 6 个预设色 + 自由取色 |
| 任务栏对齐 | 注册表 `Explorer\Advanced\TaskbarAl` | 通常需要重启资源管理器 | 「高级」里有重启按钮 |
| 壁纸 | `SystemParametersInfo(SPI_SETDESKWALLPAPER)` | 立即 | 选图 / 文件夹每 10 分钟轮换 / 还原 |
| 主题文件 | rundll32 调系统主题引擎 | 弹预览窗 | **实验性**，半通 |
| 锁屏图片 | HKLM 组策略键 | 立即 | **需要管理员**，会弹 UAC，明确提示后才执行 |

## 还原机制

- **每一个写操作之前**，原值都会记进 `%APPDATA%\WinCtlPanel\backup.json`
  （同一项只记最早的值，多次修改也不会丢原始值）。
- 浮窗里的 **「一键还原」** 把全部 6 项恢复到第一次改动前的状态，然后删掉备份文件。
- 下次启动时如果发现残留备份，会弹窗问你要不要立即还原。
- 托盘右键 → 退出：正常退出**不会**自动还原，改动保留。

## 浮窗操作

- **拖动**：按住蓝色标题栏拖
- **调大小**：右下角 `◢` 拖拽
- **置顶**：标题栏「置顶」按钮（变黄 = 开启）
- **收到托盘**：`─` 或 `✕`，托盘左键单击 / 右键菜单都能唤回；真正退出在托盘右键
- **全局热键**：`Ctrl+Alt+↑/↓` 全部显示器亮度 ±5，`Ctrl+Alt+D` 切深色/浅色
  （被其他软件占用时热键无效，但浮窗内功能不受影响，状态栏会提示）
- 位置、大小、置顶状态会记忆，下次打开还在原位

## 开机自启（自己动手）

工具**不写注册表自启动**。想要自启，把 `启动.cmd` 的快捷方式放进启动文件夹：
`Win+R` → `shell:startup` → 把快捷方式拖进去。

## 已知边界 / 坑

- 亮度**不是激活问题**：外接显示器 Windows 从来不给亮度滑块（`WmiMonitorBrightness`
  类不存在），这是 Twinkle Tray 那类工具存在的理由。本工具用同一套 DDC/CI 接口。
- 显示器 OSD 菜单里若关闭了 DDC/CI，亮度读写都会失败——失败信息会用人话显示在状态栏。
- 脚本必须保持 **UTF-8 with BOM** 编码（PowerShell 5.1 硬要求），用编辑器改完注意别被改回无 BOM。
- 运行策略受限时用：`powershell -NoProfile -ExecutionPolicy Bypass -File WinCtlPanel.ps1 -SelfTest`（自测模式）。
- 单实例互斥：重复双击只会弹「已在运行」。
