## 三、设计要求（这是重点，因为"太丑"是原始诉求）

用户原话：**"那个浮窗太丑了"**。所以这不是微调，是要做出明显好的观感。

- **视觉风格**：现代深色玻璃拟态（frosted glass）或极简扁平，二选一并贯彻到底。
  不要 WinForms 那种默认灰底按钮。
- **尺寸**：紧凑浮窗，约 360×520，不占地方
- **无边框**：靠 `--app` 模式去掉地址栏；标题栏自绘，可拖动
- **交互**：滑块要有即时反馈（拖动时数值跟着变）、按钮有 hover/active 态、切换有过渡动画
- **图标**：用内联 SVG 或 Unicode 符号，**不要外链图标库**（离线可用是硬要求）
- **中文排版**：字体栈用 `system-ui, "Microsoft YaHei", sans-serif`，字号别小于 13px
- **置顶开关** + **最小化到托盘**（如果后端做不到托盘，就做个"收起"按钮，说明差异）

**硬要求**：断网也能用（所有资源本地，无 CDN、无外链字体）。

## 四、纪律

1. **只做界面替换，不碰激活本身**——不做任何破解/KMS/激活工具。这工具只是绕过设置面板的 UI 限制
2. **每项操作前备份原值**，保留「一键还原」
3. **失败给人话**——"你的显示器不支持 DDC/CI"而不是"错误码 31"
4. `.ps1` 文件必须存成 **UTF-8 with BOM**（PowerShell 5.1 按 GBK 读中文会崩）
5. 新版本放 `D:\zcodefile\_tools\WinCtlPanel2\`，**不要覆盖原版**（原版是已验证可用的回退）
