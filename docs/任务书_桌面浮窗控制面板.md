（`WmiMonitorBrightness` 类不存在）。这恰恰是 Twinkle Tray 那类工具存在的原因。

## 二、做成什么样

一个**桌面浮窗**，不是全屏程序，不是浏览器页面：

```
┌─────────────────────────┐
│ 控制面板           ─ □ ×│   ← 无边框自绘标题栏，可拖动
├─────────────────────────┤
│ 亮度  ●──────────  30%  │   ← 拖动即时生效（DDC/CI）
│                         │
│ 外观  [深色] [浅色]      │   ← 切换即时生效
│ 强调色 ● ● ● ● ● [取色]  │
│ 任务栏 [居中] [左对齐]    │
│                         │
│ 壁纸  [选择图片…] [轮换] │
│       [应用] [还原]      │
│                         │
│ 高级  ▸ 主题 / 锁屏       │   ← 折叠区，需管理员时明确提示
└─────────────────────────┘
```

要求：

1. **无边框 + 自绘标题栏**，可拖动、可调大小、位置记忆（下次打开在同一位置）
2. **置顶开关**（有些场景要压在其他窗口上）
3. **半透明**（85% 左右，别太透影响阅读）
4. **可最小化到系统托盘**，托盘图标右键有「显示/退出」
5. **全局热键**（可选）：`Ctrl+Alt+↑/↓` 调亮度，`Ctrl+Alt+D` 切深色
6. **失败要明确告知**：哪一项不支持、为什么（比如锁屏需要管理员）
7. **每项都能还原**：改动前记原值，「还原」一键回退

## 三、技术选型（建议用这个，别折腾）

**PowerShell 5.1 + WinForms**（`System.Windows.Forms`），理由：

- **零依赖**：Windows 自带，不用装 .NET SDK、不用装 Python 包
- **能直接调 Windows API**：`Add-Type` 声明 P/Invoke，`brightness.ps1` 里已有现成的 DDC/CI 代码可直接搬
- **浮窗友好**：`FormBorderStyle=None` + 自绘 + `Opacity` 一行搞定
- **双击即用**：`.cmd` 包一层，或直接 `powershell -WindowStyle Hidden -File`

**不要**用：Electron（太重）、Python+PyQt（要装包）、WPF（要编译）。

## 四、每个功能的实现要点

### 亮度（DDC/CI）
- 复用 `brightness.ps1` 的 P/Invoke
- 滑块 0–100，拖动时**节流**（别每像素都发 DDC 命令，显示器响应慢会卡）
- 松开鼠标才真正下发，或 200ms 防抖
- 显示当前值和原始值（min/cur/max）
- 多显示器时给每个屏一个滑块

### 深色/浅色
```powershell
$P = "HKCU:\Software\Microsoft\Windows\CurrentVersion\Themes\Personalize"
Set-ItemProperty $P -Name AppsUseLightTheme  -Value 0   # 0=深色
Set-ItemProperty $P -Name SystemUsesLightTheme -Value 0
# 然后广播 WM_SETTINGCHANGE，让资源管理器/应用立刻响应
```
广播很关键——只写注册表不广播，要重启 explorer 才生效。

### 强调色
```powershell
Set-ItemProperty $P -Name AccentColor -Value <ABGR 32位整数>
Set-ItemProperty $P -Name ColorPrevalence -Value 1      # 让强调色上标题栏/任务栏
```
注意是 **ABGR** 不是 RGB 顺序，转换容易搞错，要写测试用例。

### 任务栏对齐
```powershell
$T = "HKCU:\Software\Microsoft\Windows\CurrentVersion\Explorer\Advanced"
Set-ItemProperty $T -Name TaskbarAl -Value 0   # 0=左, 1=居中
# 需重启 explorer 或广播
```

### 壁纸
```powershell
[W2]::SystemParametersInfo(0x0014, 0, $path, 0x01 -bor 0x02)
```
- 支持「选择图片」文件对话框
- 记录原壁纸路径，「还原」时设回去
- 可选：文件夹轮换（定时器）

## 五、纪律

1. **不改系统文件、不装服务、不写 HKLM**（除非用户点「锁屏」并明确同意 UAC）
2. **每个写操作前先备份原值**，存到一个 JSON（`%APPDATA%\WinCtlPanel\backup.json`），
   程序启动时如果发现残留备份，提示「上次有未还原的改动」
3. **不碰激活本身**——不做任何破解、KMS、激活工具。这个工具只是**绕过设置面板的 UI 限制**，
   不改变授权状态。这条要写进 README，避免以后误会。
4. 所有 P/Invoke 调用要检查返回值，失败时给**人话错误**（"你的显示器不支持 DDC/CI"
   而不是"错误码 31"）
5. 做成**单个目录可拷走**的形式，不写注册表自启动（用户要开机启动自己放启动文件夹）
