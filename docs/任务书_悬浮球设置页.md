# 任务书：主面板「悬浮球设置」页（可视化勾选 + 排序）

> 2026-11-07 · 下达方：ZCode（后端） · 执行方：Kimi（前端，只改 `v2-web\ui\` 三个文件）
> 后端 API 已实现并 curl 实测通过（本文所有 JSON 均为实测输出）。改动前先读 `PROJECT.md` 的分工与坑。

## 一、背景

v3 exe 带了一个 360 式悬浮球（拖动 / 贴边收起 / 点击弹功能菜单）。功能的自选目前只有托盘右键的原生子菜单，不好用。本任务把它搬进主面板：**可视化勾选 + 排序**，排序即球菜单的弹出顺序。

## 二、能力检测（必须做对的一件事）

`ui\` 是 v2/v3 共用的，但**悬浮球只存在于 v3**。v3 的 `GET /api/state` 比计划书时代的 v2 多一个字段：

```json
"ball": { "enabled": true, "functions": ["panel", "theme", "..."] }
```

**规则：`state.ball` 不存在（v2）→ 悬浮球设置入口整体隐藏**，其余功能一律不受影响。不要在 v2 上调用 ball API（会得到「未知操作」）。

## 三、后端契约（已实现，前端勿测后端、勿改后端）

### 读取

`GET /api/ball/config` →

```json
{
  "ok": true,
  "enabled": true,
  "functions": ["panel", "theme", "bright_up", "bright_down", "restore"],
  "available": [
    { "id": "panel", "label": "显示/隐藏面板" },
    { "id": "theme", "label": "深浅色切换" },
    { "id": "bright_up", "label": "亮度 +5" },
    { "id": "bright_down", "label": "亮度 -5" },
    { "id": "restore", "label": "一键还原" },
    { "id": "wallpaper", "label": "更换壁纸" },
    { "id": "wallpaper_restore", "label": "仅还原壁纸" },
    { "id": "explorer", "label": "重启资源管理器" },
    { "id": "exit", "label": "退出程序" }
  ]
}
```

- `functions`：已启用清单，**有序** = 球菜单弹出顺序
- `available`：全部 9 项（固定顺序，作为勾选池的数据源）

### 保存

`POST /api/ball/config`，body：

```json
{ "enabled": true, "functions": ["restore", "panel", "exit"] }
```

- `functions` 传**全量有序清单**，一次调用同时表达勾选与排序
- 未知 id → `500` + `{"ok": false, "message": "功能列表包含未知项：hack"}`（实测）
- 空数组 `[]` 合法（球菜单会显示提示项）
- 响应 = 保存后的完整 payload（同 GET 形状），以它为准重渲染
- `enabled=false` 后端**立即**隐藏球；`true` 立即显示/创建
- 请求头照旧：`X-WinCtl-Token`（现成的 `api()` 帮助函数已带）；`Content-Type: application/json`

## 四、前端需求

1. **入口**：「更多工具」dialog 的 tool-list 里新增一行「悬浮球设置」（沿用现有 tool-list 行样式），点击打开一个子 `<dialog>`。整行受 `state.ball` 能力检测控制（见 §二）。
2. **开关**：「启用悬浮球」开关，样式跟随面板现有的 segmented/开关视觉语言。
3. **勾选**：9 项功能，每项复选框 + label（label 用后端 `available[].label`，不要前端硬编码文案）。
4. **排序**：对已勾选项排序——原生拖拽（HTML5 DnD）或上移/下移按钮均可，**零依赖**；顺序改动即时反映在一个「球菜单预览」区（把 `functions` 顺序渲染出来，让用户所见即所得）。
5. **保存策略**：**即时保存**——每次勾选/排序变化立即 `POST`；失败时回滚 UI 到上一个成功状态并走现有 `friendlyError` 提示（参考 `chooseAccent` 的 catch-rollback 模式）。不要做「保存」按钮（面板其他设置都是即时的）。
6. **空列表**：全部取消勾选时，列表下方显示非阻断提示（如「未选择功能时，点击悬浮球不会弹出菜单」）。
7. **样式**：沿用现有 design tokens 与深浅色变量；**CSP 禁止一切外链资源**（现有 CSP 会直接拦）；380px 宽度内可用；深浅两主题都过一遍。
8. 中文引号一律「」。
